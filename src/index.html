Darwin you can boot.

PureDarwin is a free operating system built from Apple's open source Darwin releases. Apple publishes the kernel and much of the Unix userland, but never enough to boot a computer. We combine and extend existing open source projects, and write our own code where nothing exists, to provide a bootloader, drivers, frameworks, a desktop and the build that puts them together.

Built on

PureDarwin stands on a lot of other people's work. The kernel and most of the core system are Apple's Darwin open source releases. AppKit, CoreGraphics, CoreData and the Onyx2D drawing engine started from Cocotron, by Christopher J. W. Lloyd and its contributors, by way of the copies ravynOS carries. Foundation grew from the small first version in NeoDarwin's Foundation, and dyld and corecrypto come through NeoDarwin. The Metal frontend is Darling Metal. Drivers run on code from FreeBSD and Haiku, ACPI on uACPI, XPC on NextBSD's libxpc, and the desktop on Wayland, wlroots, neuswc and Mesa. The compiler is LLVM.

Our own work is what ties these together and fills the gaps between them. The Credits page says what came from where, and what PureDarwin added to it.

What works today

On a PC, PureDarwin boots to its own desktop, Argon, in QEMU or on real hardware. It has drivers for AMD, Intel and NVIDIA graphics, wired and Wi-Fi networking, and ext4 disks. There's a terminal, a file manager, settings, a text editor, an image viewer and a few other apps, Wine for Windows programs, and a compiler that runs on PureDarwin itself.

On arm64 it boots to a shell in QEMU, and there's a QEMU image with a Wayland desktop too. Real arm64 boards are earlier along. The NVIDIA Jetson TX1 has booted to the desktop, the Orange Pi Zero 3 and Zero 4 have board support but haven't been tested on hardware yet, and more boards are in bring-up.

PCs can boot it from UEFI or a legacy BIOS. Secure Boot works with an image you build yourself, because signed downloads aren't published yet.

The images are the latest successful builds from our Hydra build server, compressed with zstd, and each one has its own sha256 file next to it.

Check the download with sha256sum -c, then unpack it with zstd -d before you write it to a disk. The recording's checksum is in SHA256SUMS.

Or build it yourself

Nix is the build system, so all you need is a Linux host with flakes enabled: 

git clone https://github.com/PureDarwin/PureDarwin
cd PureDarwin
nix build .#image-minimal
nix run .#vm

The build assembles its own SDK from open source headers, so no Apple files are needed and the repository and Nix are all it takes.

Frequently asked questions

What is Darwin?

Darwin is the open source core of Apple's operating systems. It's made up of the XNU kernel and a large part of the Unix userland, and Apple publishes it under the Apple Public Source License.

Every Mac and iPhone runs on Darwin. Apple used to release bootable Darwin images you could install, but it stopped in the mid 2000s, and today it publishes Darwin as source code only.

What is PureDarwin?

PureDarwin is a community project that turns Apple's Darwin releases into an operating system you can boot.

We combine and extend existing open source projects, and write our own code, such as the bootloader and the desktop, where nothing exists. The Credits page says what came from where.

PureDarwin isn't affiliated with or endorsed by Apple, and our images contain no proprietary Apple binaries.

What can I do with it?

It's a system for developers and the curious, and it isn't ready to be a daily driver yet. Today you can:

  • boot a real Darwin system in QEMU or on hardware
  • use the Argon desktop and its apps
  • run Windows programs through Wine
  • compile software with the compilers that run on PureDarwin itself
  • explore how the XNU kernel works outside Apple's systems

See what works today for the details.

Can it run macOS or iOS apps?

Some macOS apps, and the list is growing.

Graphical Mac apps rely on frameworks Apple has never published as source, such as AppKit and Metal, so we provide our own. Our AppKit started from Cocotron and we've extended it a lot. It runs the apps that come with PureDarwin, and a growing set of unmodified Mac apps start and run, including Firefox and TextMate.

Plenty of Mac apps still don't run, usually because they need a framework or interface we haven't written yet.

Command-line Darwin software and most open source software build and run, and Wine runs Windows programs on the desktop.

Is it free? Can I contribute?

Yes. Everything we write is open source, and code from Apple and other projects keeps its own licence.

Development happens in the open on GitHub. Porting and packaging software is the best place to start, and the contribution guide explains the rest.
