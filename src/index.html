What works today

PureDarwin boots to the Argon desktop on x86_64, and to a shell on arm64 in QEMU and on a growing list of boards.

  • x86_64 The Argon desktop on QEMU and real hardware, with AMD, Intel and NVIDIA GPU drivers. The release target.
  • arm64, QEMU virt Boots to a shell, with a Wayland image available.
  • NVIDIA Jetson TX1 arm64, Tegra X1.
  • Orange Pi Zero 3 arm64, Allwinner H618.
  • Orange Pi Zero 4 arm64, Allwinner A733.
  • And other boards in bringup

On x86_64 that means an ext4 root, wired networking and Wi-Fi with DHCP end to end, OpenGL on real GPUs, Wine running Windows GUI applications, and a compiler toolchain that runs on PureDarwin itself. It boots with UEFI, Secure Boot or a legacy BIOS.

Or build it yourself

Nix is the build system. On a Linux host with flakes enabled: 

git clone -b upstream-xnu-12377 https://github.com/PureDarwin/PureDarwin
cd PureDarwin
nix build .#image-minimal
nix run .#vm

No Apple files are needed. The build assembles its own SDK from open source headers, so the repository and Nix are all it takes.

Frequently asked questions

What is Darwin?

Darwin is the open-source core of macOS and iOS: the XNU kernel plus a large part of the Unix userland, published by Apple under the Apple Public Source License. Every Mac and iPhone runs on it, but Apple only ships it as source code. There is no Darwin you can install from Apple.

What is PureDarwin, and what is it not?

PureDarwin is a community project that turns Apple's Darwin releases into a standalone, bootable operating system. We write the missing pieces ourselves: the bootloader, drivers, init and a desktop. PureDarwin is its own system. It is no macOS clone, and it is not affiliated with or endorsed by Apple. There are no proprietary Apple binaries in our images.

What can I actually do with it?

Boot a real Darwin system in QEMU or on hardware, use the Argon desktop and its apps, run Windows programs through Wine, compile software with the on-system toolchain, and explore how the XNU kernel works outside of macOS. It is a system for developers and the curious. It is not ready to be a daily driver yet. See what works today.

Can it run macOS or iOS apps?

A select few. Graphical macOS apps are built against frameworks Apple never open sourced, so PureDarwin reimplements them. Its own AppKit runs the built-in apps, and a handful of unmodified macOS apps run as well, Firefox among them. Most macOS apps do not run yet. Command-line Darwin software and open source software generally work, and Wine runs Windows GUI applications on the desktop.

Is it free? Can I contribute?

Yes. Everything we write is open source, and Apple's code stays under the APSL. Development happens in the open on GitHub. Packaging is the most useful place to start, and the contribution guide explains the rest.
