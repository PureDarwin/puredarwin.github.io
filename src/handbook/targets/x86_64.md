# x86_64

The main target, and the one releases are built around.

## Building

```
nix build .#kernel.kernel     # or .#kernel.kernel-debug
nix build .#kernel.kexts
nix build .#kc.default
nix build .#image-minimal     # or .#image-wayland for the desktop
nix run .#vm                  # or .#kvm
```

`.#image` is the full image, which also boots from a BIOS and from 32-bit UEFI.
`.#image-sb` is that image signed for Secure Boot. See
[Image Flavours](../images/flavours.md).

## What Works

**Booting and the core system.** It boots from an ext4 root in QEMU and on real
hardware, through UEFI, Secure Boot, 32-bit UEFI or a BIOS. launchd, XPC and notifyd
run, and `ioreg`, `sw_vers` and the rest of the userland work.

**Filesystems.** ext4 as the root, with a journal. HFS+ and APFS work as a root too, on
`image-hfs` and `image-apfs`. msdosfs is there for FAT disks.

**Networking.** DHCP works from start to finish through configd, DNS through
mDNSResponder, and curl in the guest. Wired drivers cover virtio-net, the Intel e1000
family, Intel I225 and I226, and Realtek RTL8111, RTL8125 and RTL8126. Wi-Fi covers the
Realtek RTL8852B and RTL8852C, USB adapters with the Realtek RTL8192EU, and the Ralink
RT3572.

**Graphics.** The AMD, Intel and nouveau NVIDIA drivers are Linux drivers from FreeBSD's
drm-kmod, running on PureDarwin's driver compatibility layer. Newer NVIDIA cards
(Maxwell, Pascal and Volta) can use NVIDIA's own 580 driver instead. Mesa provides
OpenGL on real GPUs, a software renderer as a fallback, and virgl and Venus in virtual
machines. When no GPU driver attaches, the firmware framebuffer keeps the desktop going.

**Desktop.** Argon, the PureDarwin desktop, runs on the neuswc Wayland compositor. It
has a menu bar, a Dock, Files, Terminal, Settings, Calculator, System Information, a
text editor and an installer. The apps are AppKit apps, and Xorg and sway are also available.

**Applications.** Wine runs Windows programs with a graphical interface, GTK3 and
WebKitGTK work, and a few unmodified macOS programs run, Firefox among them.

**Compilers on the system.** cmake, ninja, meson, clang, tcc and rustc all run on
PureDarwin itself, so you can build software inside it.

**Audio.** `RavynHDAudio` drives Intel HD Audio.

## Hardware Support

* Storage over AHCI, ATA, NVMe and USB.
* USB through EHCI, OHCI, UHCI and xHCI.
* PS/2 and USB keyboards and mice.
* Graphics as described above, with the firmware framebuffer as a fallback.
* virtio disk, network and GPU devices in virtual machines.

Some machines need the notes in [Running on Real Hardware](../images/hardware.md).
